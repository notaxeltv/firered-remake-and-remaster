| `RUST-CODEX-STATUS.md` | Codex batch log |
| `RUST-GEMINI-STATUS.md` | Gemini / Antigravity batch log |

| `TOKEN-SAVERS.md` | Graphify / RTK / usage tips for agents |
| `3D-REMAKE-DESIGN.md` | Longer-term 3D remake notes |
| `reports/` | Archived analysis PDFs |

Read `STATE.md` before starting work; update it when something ships.
For Rust changes, read `CONTRIBUTING-RUST.md` and the latest ownership notes in
`RUST-COLLABORATION.md` first.
